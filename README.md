## Featured Project

### Library Management System

A web-based library management system developed as a software engineering project.

The system supports two main perspectives:

- **Readers:** search and filter books, manage favorites, add books to a borrowing cart, create borrowing requests, and review borrowing history
- **Librarians and administrators:** manage books, readers, employees, accounts, borrowing and return slips, imports, authors, categories, publishers, suppliers, penalties, statistics, and permissions

My main contributions included:

- Analyzing the library's business processes and functional requirements
- Designing and documenting use cases, sequence diagrams, activity diagrams, and BFD diagrams
- Structuring the functional scope and helping the team maintain consistency across documents and implementation
- Developing the web application and connecting the user interface with the database
- Guiding team members while they created diagrams and implemented related modules
